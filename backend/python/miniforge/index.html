1. 概述

  • miniforge官方地址 https://github.com/conda-forge/miniforge 。
  • miniforge下载地址 https://conda-forge.org/download/ 。
  • 国内可以在清华大学开源镜像站上下载相关的包，https://mirrors.tuna.tsinghua.edu.cn/github-release/conda-forge/miniforge/Release%2025.3.1-0/.

  • 测试环境CentOS Linux release 7.9.2009 (Core)。
